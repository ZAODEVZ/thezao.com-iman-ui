# thezao.com-iman-ui

A one-page concept for The ZAO's homepage, built by IMan in July 2026. It is a single `index.html` (no build step) with sections for WaveWarZ, Respect, what we build, notable artists and builders, and a join call.

**Status:** concept, not canonical. On 21 Oct 2026 The ZAO decided to rebuild thezao.com as the front door in [bettercallzaal/zao-website](https://github.com/bettercallzaal/zao-website). That repo is the canonical home for thezao.com; this one is kept as a design reference.

- Preview: https://thezao-com-iman-ui.vercel.app
- Edit: open `index.html`, change it, push. Vercel redeploys the preview.
